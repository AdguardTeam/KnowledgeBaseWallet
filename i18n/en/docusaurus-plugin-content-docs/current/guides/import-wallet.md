---
title: How to import an existing wallet
sidebar_position: 3
---

You can import an existing wallet into AdGuard Wallet using your seed phrase or a cloud backup. AdGuard Wallet supports wallets from any BIP39-compatible app, including MetaMask, Phantom, and Trust Wallet.

AdGuard Wallet offers three import methods:

- **Import manually** — enter your seed phrase (12, 18, or 24 words)
- **Import from iCloud** — restore from an iCloud backup
- **Import from Google Drive** — restore from a Google Drive backup

## Import manually

1. Open AdGuard Wallet and tap _Import wallet_.
2. Select _Import manually_.
3. Enter your seed phrase. You can type it or paste it.
4. If the seed phrase is valid, your wallet will be imported. If you see “Invalid seed phrase,” check the words and try again.

<!-- screenshot: Import wallet screen — seed phrase input field with paste button -->

:::warning

Be careful with unfamiliar seed phrases. Some scammers create a wallet, give away its seed phrase, and wait for someone to send funds to it — then drain them. Only import a seed phrase from a wallet you created yourself.

:::

If the wallet is already in your AdGuard Wallet, you will see “This wallet is already added.”

## Import from iCloud or Google Drive

1. Open AdGuard Wallet and tap _Import wallet_.
2. Select _Import from iCloud_ or _Import from Google Drive_.
3. Select the wallet you want to import from the list of your cloud backups.
4. Enter the password you set when creating the backup.

<!-- screenshot: Cloud backup import — list of backed-up wallets with dates -->

If no backups are found, try importing manually with your seed phrase instead.
