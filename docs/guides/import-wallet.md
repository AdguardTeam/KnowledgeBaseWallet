---
title: How to import an existing wallet
sidebar_position: 3
---

You can import an existing wallet into AdGuard Wallet using your seed phrase or a cloud backup. AdGuard Wallet supports wallets from any BIP39-compatible app, including MetaMask, Phantom, and Trust Wallet.

AdGuard Wallet offers three import methods:

- Import manually — enter your seed phrase (12, 18, or 24 words)
- Import from iCloud — restore from an iCloud backup
- Import from Google Drive — restore from a Google Drive backup

## Import with a seed phrase

1. Open AdGuard Wallet and tap *I have a wallet*.
    ![Onboarding *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/onboarding.png)
1. Select *Import manually*.
    ![Import method *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/import_method.png)
1. Enter your seed phrase. You can type it or paste it.
    ![Enter seed phrase *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/enter_seed_phrase.png)
1. Name your wallet. Done!

:::warning

Be careful with unfamiliar seed phrases. Some scammers create a wallet, give away its seed phrase, and wait for someone to send funds to it — then drain them. Only import a seed phrase from a wallet you created yourself.

:::

## Import from iCloud or Google Drive

1. Open AdGuard Wallet and tap *I have a wallet*.
    ![Onboarding *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/onboarding.png)
1. Select *Import from iCloud* or *Import from Google Drive*.
    ![Import method *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/import_method.png)
1. Select the wallet you want to import from the list of your cloud backups.
    ![Backups *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/wallet_backups.png)
1. Enter the password you set when creating the backup.
    ![Enter password *mobile](https://cdn.adtidy.org/content/kb/wallet/guides/enter_password.png)
1. Name your wallet. Done!

If no backups are found, try importing manually with your seed phrase instead.
