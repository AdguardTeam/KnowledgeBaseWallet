---
title: How to manage multiple wallets
sidebar_position: 9
---

AdGuard Wallet lets you create and manage multiple wallets. You can switch between them, rename them, and delete them as needed.

To add a wallet:

1. Go to the *Wallets* screen.
1. Tap *Add wallet*.
<!-- screenshot: Wallets screen with Add wallet button -->
1. Choose to create a new wallet or import an existing one.
1. Give your wallet a name to easily tell your wallets apart.

You can also add wallets from the *Settings* screen under *Wallet settings*.

<!-- screenshot: Wallets list screen — multiple wallets with names, balances, and active wallet indicator -->

## Switching between wallets

If you have more than one wallet, you can switch between them. Your account name will appear in the header with a switcher icon. Tap it to see and select your other wallets.
<!-- screenshot: List of all wallets -->

## Naming a wallet

When you create or import a wallet, you can give it a custom name. If you don’t choose one, a default name will be used. Names are only visible to you.

<!-- screenshot: Name your wallet screen — text input with keyboard and done button -->

To rename a wallet later, go to *Wallet settings* and edit the name.

## Account discovery on import

When you import a wallet using a seed phrase, AdGuard Wallet can detect if there are multiple accounts associated with that seed phrase. You can choose which accounts to add.

For more details, see [How to manage accounts](/guides/manage-accounts).

## Deleting a wallet

1. Go to the wallet you want to delete.
1. Open *Wallet settings* and tap *Delete wallet*.
1. If you have a backup copy, you can delete it as well. If you don’t, confirm that you understand the wallet cannot be restored without a seed phrase or cloud backup.

<!-- screenshot: Delete wallet confirmation — Remove wallet? dialog with backup options -->

:::warning

The first account in a wallet cannot be deleted. Deleting a wallet without a backup means you may lose access to those funds permanently if you don’t have the seed phrase.

:::
