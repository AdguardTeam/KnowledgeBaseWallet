To receive crypto in AdGuard Wallet, share your wallet address or QR code with the sender. Make sure the sender uses the correct network.

To receive crypto:

1. Open AdGuard Wallet and go to the *Receive* screen.
1. Select the asset you want to receive.
1. If the asset exists on multiple networks, ask the sender which network they will use — and select the same one.
1. Your address and QR code will be displayed. Share them with the sender.

<!-- screenshot: Receive screen — QR code, wallet address, and network selector -->

1. After the transaction is sent, it will appear in your transaction history.

You can also copy your address to the clipboard, share it through other apps, or download the QR code as an image.

<!-- screenshot: Share options — copy address, share via other apps, download QR code -->

:::warning

Always confirm the correct network with the sender. On EVM networks (Ethereum, BSC, Polygon, etc.) and Solana, the same address can receive different assets — but if the sender selects the wrong network, the funds may be lost.

:::

## Network selection

If an asset exists on multiple blockchains (for example, USDT on Ethereum, Polygon, and Tron), you need to select which network to use. Make sure the sender selects the same network — otherwise, the assets will be lost.

<!-- screenshot: Network selection dialog — USDT network picker (Ethereum / Polygon / Tron) -->

For details on networks supported by AdGuard Wallet, see [What is AdGuard Wallet](/overview/what-is-adguard-wallet).
